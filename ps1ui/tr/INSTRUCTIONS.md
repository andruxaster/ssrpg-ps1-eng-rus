# Задача: перевести на русский строки интерфейса PS1-версии Samurai Shodown RPG (Shinsetsu Samurai Spirits Bushido Retsuden)

Диалоги уже переведены. Теперь - меню, предметы, приемы, имена врагов, боевые и системные сообщения. Источник - японский текст.

Файл batch_N.json - список элементов:
- `uid`
- `jp`: японская строка (может быть фрагментом: игра склеивает фрагменты с именем героя, предмета или числом).
- `max_chars`: МАКСИМУМ символов в переводе (включая пробелы). Жесткий предел места в файле - превышать нельзя.
- `where`: что это за строка.
- `context`: соседние строки в файле (текущая помечена `>> `). По ним понятно, к чему относится фрагмент (например, описание предмета, разбитое на строки, идет снизу вверх - смотри соседей).

Выход: файл out_N.json, ОДИН JSON-объект `{"<uid>": "перевод", ...}` для КАЖДОГО uid.

Правила:
1. Длина перевода <= max_chars. Сокращай разумно (Зел. лечения, Защ., Ск.), сохраняя смысл. Если строка - отладочная/мусор/тестовая (デバッグ, ダミー, ＸＸ奥義０Ｃ, случайные символы вроде λπ√ или ⑫⑬), ставь пустую строку "" - она останется как есть.
2. Символы ТОЛЬКО: русские буквы (без Ё/ё), цифры, пробел, . , ! ? ' - ( ) : / + %. Латиницу не использовать, кроме LV, ON, OFF, GP, HP (можно перевести и по-русски).
3. Терминология и имена: GLOSSARY_RU.md и NGCD_UI_REF.tsv (это русский перевод интерфейса той же игры для Neo Geo CD: колонки kind / EN / RU). Если японская строка соответствует предмету/приему/врагу из NGCD - бери РУССКОЕ название оттуда (сокращай, если не влезает). Названия приемов героев - как в NGCD RU. Японские названия без аналога - переводи по смыслу или транскрибируй (по Поливанову, айнские слова Накоруру/Римуруру - транскрипцией: Камуй Мутубэ).
4. Пробелы в начале строки (выравнивание, полноширинные　) переводи как обычные пробелы и по возможности сохрани выравнивание по правому краю (для описаний, где первая строка с отступом).
5. Фрагменты: если строка идет после имени (например 'は、' / 'の攻撃！' / 'を手に入れた'), переводи так, чтобы склейка 'Имя' + перевод читалась ('の攻撃！' -> ' атакует!', 'を手に入れた' -> ' получен(а)' и т.п.). Начинай с пробела, если перед ним вставится имя/предмет.
6. Числа и полноширинные цифры/буквы (ＬＶ, １) - обычными (LV, 1).

После записи запусти `python3 -I check.py batch_N.json out_N.json` и исправляй до `errors 0`.
