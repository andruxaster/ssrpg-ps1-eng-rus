# Задача: перевести на русский реплики RPG Samurai Shodown RPG (PS1-версия)

Это реплики, которые есть только в PS1-версии (их нет в Neo Geo CD). Остальная игра уже переведена на русский, нужно сохранить тот же стиль и термины.

JSON-файл с пачкой. Каждый элемент:
- `id`
- `pages`: английские страницы (перевод с японского, сделанный для этого порта). Каждая страница - отдельное окно текста. Переводи их.
- `jp`: японский оригинал (страницы через ' / ') - для сверки смысла и тона.
- `choice`: null или {question, options} - вопрос и варианты выбора.
- `context`: соседние реплики, `{"self": true}` - место текущей. Реплики с `ru` - это уже готовый русский перевод (взят из русской версии для Neo Geo CD, он считается эталоном): подстраивайся под его стиль, термины, голоса персонажей и обращение на ты/вы. Реплики с `en` еще не переведены.

Выход: ОДИН JSON-объект в файл out_XX.json: `{"<id>": {"pages": ["...", ...], "question": "...", "options": ["...", ...]}, ...}` (question/options только если есть choice; question можно опустить, если в choice question = null).

Правила:
1. Ровно столько же страниц, сколько в `pages`, в том же порядке. Окно - 2 строки по 32 символа; старайся держать страницу в пределах ~64 символов (до ~90 допустимо, перенесется в следующее окно). Без переносов строк.
2. `{NAME}` - имя героя, подставляемое игрой. Сохрани каждый `{NAME}` столько же раз, в естественном месте (лучше обращение или именительный падеж - склонять нельзя).
3. Символы ТОЛЬКО: русские буквы А-Я а-я (БЕЗ Ё/ё - пиши е), цифры, пробел и . , ! ? ' - ( ) : /  и латинское GP для денег. Никаких кавычек "", «», символа многоточия (пиши ...), длинного тире (пиши -), латиницы кроме GP, ; & * ~.
4. Вопрос выбора <= 32 символов, каждый вариант <= 12 символов (Да / Нет, Купить / Нет, Съесть / Не есть). Для меню сохраняй порядок вариантов.
5. Имена и названия - строго по GLOSSARY_RU.md (поливановская транскрипция японских имен: Дзюбэй, Хандзо, Сиро).
6. Стиль: живой литературный перевод игры 90-х, не подстрочник. Голоса: Галфорд и Эрсквейк вставляют английские словечки ('Окей', 'Йе!'), Чам-Чам и Пак-Пак говорят по-детски/коряво, Шарлотта - высокопарно, Хаомару - грубовато-разговорно, старики - степенно. Междометия: Ха-ха-ха, Хм..., Гр-р... Мысли в скобках оставляй в скобках. Деньги: '100 GP'.
7. Обращение на 'вы'/'ты' - по контексту.
8. Не добавляй и не выкидывай смысл. Если английский явно ошибается относительно японского - следуй японскому.

После записи запусти `python3 -I check_ru.py batch_XX.json out_XX.json` в этой папке и исправляй, пока не будет `errors 0`.
